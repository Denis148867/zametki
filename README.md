# 📝 Notes App — Flask

Простой сайт для создания и просмотра заметок, сделанный на **Python и Flask**.

## 📌 О проекте

Это веб-сайт заметок, где можно:

* 📖 просматривать заметки;
* ➕ добавлять новые заметки;
* 🗑️ удалять заметки;
* 🔎 открывать отдельную заметку.

## 🛠️ Используемые технологии

* **Python**
* **Flask**
* **HTML**
* **CSS**
* **JSON**

## 🚀 Запуск проекта

1. Установите Python.
2. Установите Flask:

```bash
pip install -r requirements.txt
```

3. Запустите файл:

```bash
python run.py
```

4. Откройте сайт в браузере:

```text
http://127.0.0.1:5000
```

## 💡 Как работает сайт

Главная страница показывает список заметок.

При нажатии на заметку открывается её отдельная страница.

На отдельной странице есть возможность удялять и редактировать заметки.

Заметки хранятся в файле `notes.json`.

Flask обрабатывает запросы пользователя и показывает нужные HTML-страницы.
